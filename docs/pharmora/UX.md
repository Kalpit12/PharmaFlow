# Pharmora — UX

## Users

- **Internal commercial / management** — primary Phase 1 experience (`AppShell` + sidebar).  
- **Distributor** — separate, lighter portal (`/distributor`).  
- **Public / website visitor** — `/ask` (later), trustworthy product enquiry, not a generic chatbot.

## Mental model

One workspace: **what needs attention**, **who to serve**, **what we sell**, **what is in motion** (RFQs → quotes → orders), **what we know** (documents + AI grounded in demo sources).

## Navigation (planned)

- Overview  
- AI Assistant  
- Commercial: Leads, Customers, RFQs, Quotations, Orders  
- Products: Catalogue, Product Intelligence  
- Documents  
- Analytics  
- Operations: Inventory, Production, Regulatory (Coming soon as needed)  
- Administration / Settings  

Incomplete modules: labelled **Coming soon**, not fake-deep.

## Page principles

1. Identify the page in the header.  
2. Lead with the decision or metric that matters.  
3. Offer a clear next action.  
4. Use AI as insight + actions + sources — never as a ChatGPT clone.

## Key flows (later pages)

Dashboard → RFQs / sales · Products → detail → request quote · RFQ detail → create quote / contact · Customer 360 · Documents ask · Global search and ⌘/Ctrl+K.

## Density

Desktop-first enterprise density. Tables on large screens; stacked cards on small. Persistent sidebar ≥1024px; collapsible tablet; drawer on mobile.

## Feedback

Toasts for confirmations, dialogs for destructive/irreversible, skeletons instead of blank waits, empty states that explain value and offer an action.

## Copy

Specific pharmaceutical commercial language. No lorem ipsum, no generic SaaS filler, no medical advice, no fabricated clinical claims.

## AI UX

Workspace layout (history / conversation / context). Answers: concise insight, supporting data, sources, recommended actions. Mock only in this phase.
